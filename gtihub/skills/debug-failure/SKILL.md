# Skill Name

Debug Failures

Analyze failed executions and identify the root cause.

- Execution Failures
- Script Issues
- Locator Issues
- Data Issues
- Environment Issues
- Application Issues

## Review

- Logs
- Reports
- Screenshots
- Error Messages

## Identify

- Root Cause
- Failure Category
- Impact

## Output

- Root Cause Analysis
- Failure Summary
- Suggested Fix
