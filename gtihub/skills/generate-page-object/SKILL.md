# Skill Name

Generate Page Object

## Purpose

Create or update page resources for Robot Framework automation.

## Responsibilities

- Identify pages
- Identify elements
- Generate page resources
- Generate locators
- Generate page keywords
- Reuse existing page resources

## Input

- Test Scenarios
- Test Cases
- Existing Page Resources

## Follow

- instructions.md
- Existing page resources

## Verify

- Required pages are covered
- Required locators are available
- Page keywords are reusable
- Duplicate resources are avoided

## Output

- New Page Resources
- Updated Page Resources
- Locator Definitions
- Page Keywords
