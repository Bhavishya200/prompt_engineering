# Skill Name

Review Locators

## Purpose

Review locator quality, stability, and reusability.

## Responsibilities

- Review locator naming
- Review locator reuse
- Identify weak locators
- Identify duplicate locators

## Input

- Page Resources
- Locator Definitions

## Verify

- Locators are unique
- Locators are stable
- Locator names are meaningful
- Preferred locator strategy is followed
- Existing locators are reused

## Identify

- Duplicate locators
- Unused locators
- Dynamic locators
- Long or complex locators

## Output

- Locator Review Report
- Issues Found
- Improvement Suggestions
- Optimized Locators
