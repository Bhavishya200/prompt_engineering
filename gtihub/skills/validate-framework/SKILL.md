# Skill Name

Validate Framework Design

## Purpose

Review framework organization and maintainability.

## Input

- Framework Structure
- Resources
- Test Scripts

## Responsibilities

Validate:

- Reusability
- Maintainability
- Scalability
- Organization

## Verify

- Resources are separated
- Tests are separated
- Test data is externalized
- Framework is reusable

## Identify

- Duplicate resources
- Unused files
- Poor organization
- Framework risks

## Output

- Framework Review
- Design Findings
- Improvement Suggestions
