# Skill Name

Validate Robot Automation

## Purpose

Validate Robot Framework automation implementation.

## Input

- Robot Scripts
- Resource Files
- Page Resources

## Responsibilities

Validate:

- Test Flow
- Assertions
- Keyword Usage
- Resource Usage
- Test Data Handling

## Verify

- Tests match test cases
- Assertions are present
- Resources are imported correctly
- Keywords are used correctly

## Identify

- Missing assertions
- Incorrect keyword usage
- Duplicate automation logic
- Missing validations

## Output

- Pass / Fail Status
- Issues Found
- Improvement Suggestions
